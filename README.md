Dashboard de Faturamento e Operações Logísticas

Dashboard desenvolvido em Power BI com dados do Excel, inspirado em processos reais de logística e faturamento que vivenciei ao longo da minha trajetória profissional na área.

Aviso: os dados utilizados neste projeto são fictícios e foram gerados exclusivamente para fins de portfólio. Nomes de clientes, funcionários e valores não representam nenhuma empresa ou pessoa real.

Sobre o projeto

O dashboard é dividido em 3 páginas, cada uma focada em uma frente de análise:

Análise de Faturamento — faturamento mensal, ticket médio, prejuízo devoluções, crescimento, comparação entre modalidades de envio e ranking de clientes
Análise de Envios — volume de caixas, devoluções por estado, classificação por tamanho e taxa de entrega
Análise de Performance — produtividade por funcionário, tempo médio por operação e notas faturadas

Tecnologias
Power BI Desktop
DAX (medidas calculadas)
Modelagem de dados

Objetivo

Este projeto faz parte da minha jornada de transição para a área de Análise de Dados, unindo minha experiência prática em logística com as habilidades técnicas que venho desenvolvendo em Power BI, Excel e análise de dados.
